## 这是什么

用 MotionGit(.motion) 开源模板一键出知识讲解/口播视频。用户说"做条口播视频""知识讲解视频""用阿杜那套模板""酷炫科技风""用模板剪片"，或给出主题+文案想要 60fps 横屏知识视频时使用。自动选模板、自动装包、一条命令跑完 方案→预览→成片。

## 怎么用

把这个目录放进 Agent 的 skills 目录即可（Claude Code、Codex 等支持 SKILL.md 的 Agent 通用）。
